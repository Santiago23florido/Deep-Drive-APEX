# Pose-dataset tracks

Generated by `simulation/tools/generate_pose_dataset.py --install-gazebo-worlds`
from `simulation/tools/pose_dataset/config/tracks.yaml`; do not edit by hand.
They are the exact tracks of the multi-scenario LiDAR–IMU pose dataset
(`simulation/tools/pose_dataset/README.md`), `zs_*` being the zero-shot tracks
kept out of the dataset (`ZERO_SHOT.md`).

Launch one with the APEX stack (after `colcon build --packages-select rc_sim_description`):

```bash
./simulation/tools/sim/apex_sim_up.sh --scenario pose_<track> --rviz
```

`tracks_index.json` lists every world with its scenario name, spawn pose,
split role, reference length and lane width.
